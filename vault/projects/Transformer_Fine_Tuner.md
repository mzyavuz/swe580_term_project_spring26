# Transformer Fine Tuner

# Project: Transformer Fine Tuner

This project is dedicated to creating a flexible and powerful tool for fine-tuning transformer models.

## Core Ideas

The project builds directly on the foundational research in [[research/Transformers.md]] and [[research/BERT.md]]. The goal is to apply these concepts in a practical, reusable way.

## Implementation

The implementation will heavily leverage the existing [[projects/Fine_Tuning_Pipeline.md]], extending it with new features specific to the latest models, such as parameter-efficient fine-tuning (PEFT) methods like LoRA.
